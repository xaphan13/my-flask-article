# 02 — Насколько современен подход

> Оценка фронтенд-слоя по состоянию на 2026-08-31 (ветка `new-frontend`, HEAD
> `b12f62c`), после заданий 003 (Bootstrap 5.3.8) и 004 (доводка светлой темы и
> подсветки кода). Вердикт: **архитектура, стек и темы — современные; остались
> хвосты миграции (сайдбар-заглушка) и фаза доставки статики.**

## 1. Общая оценка

| Критерий | Оценка | Обоснование |
|---|---|---|
| Парадигма (SSR вместо SPA) | 5 / 5 | Jinja-рендеринг идеален для статей: SEO, скорость первого отклика, нет клиентского состояния |
| Иерархия шаблонов Jinja | 4 / 5 | единый `layout.html`, партиалы, макросы (футер, формы); минус — сайдбар-заглушка, переживший миграцию |
| Актуальность CSS-фреймворка | 5 / 5 | Bootstrap 5.3.8 — актуальная линейка, подключён с jsdelivr + SRI |
| Актуальность JS-библиотек | 5 / 5 | jQuery и Popper удалены; остались только Bootstrap 5 bundle и highlight.js 11.12.0 — оба актуальные |
| Качество собственного JS | 4 / 5 | IIFE, `'use strict'`, `addEventListener`, без inline-обработчиков и глобальных функций; ES5-стиль (`var`) и подключение без `defer` — мелочи |
| Темы (светлая/тёмная) | 5 / 5 | нативный `data-bs-theme` + CSS-переменные, восстановление до первой отрисовки без вспышки, единый файл стилей |
| Подсветка кода | 4 / 5 | hljs 11.12.0, 15 тёмных тем на выбор, синхронизация с темой сайта; минус — 16 CSS-файлов предзагружаются на каждой странице |

| Безопасность фронтенда | 4 / 5 | SRI + `crossorigin` на всех внешних ресурсах; единственный inline-JS — восстановление темы; нет CSP |

## 4. Что осталось (дефекты и хвосты)

### 4.1 Сайдбар-заглушка не удалена (LOW)

Решение 6 задания 003 («сайдбар-заглушка удаляется полностью») выполнено
частично: удалён JS, но остались `_sidebar.html`, сетка `container-fluid` +
`col-md-2`/`col-md-10` в `layout.html` и стили `.sidebar`/`.margin-right-sidebar`
в `base.css`. Пользователь на каждом экране шире `md` видит пустую колонку
«Раздел 1/2/3», пункты которой никуда не ведут. Отчёт задания 003 утверждает
обратное — расхождение между отчётом и деревом.

### 4.2 16 предзагруженных таблиц hljs (LOW)

Все 16 CSS-тем highlight.js подключены в `<head>` (одна активна, остальные
`disabled`). Браузер скачивает `disabled`-таблицы так же, как обычные — это
16 лишних запросов на каждой странице (каждый ~1–2 КБ, суммарно ~20–30 КБ).
Плата за мгновенное переключение темы без вспышки; осознанный трейдофф, но
при желании сокращается до двух таблиц (активной + светлой) с подменой `href`.

### 4.3 Хрупкое понижение заголовков в статье (LOW)

`art_author.html` делает `art.content | replace('<h1>', '<h2>')` — строковая
замена без разбора HTML. Если в теле статьи появится `<h1>` внутри
`<pre><code>` (пример HTML-кода), он будет испорчен. Сейчас статей с таким
контентом нет, поэтому дефект латентный.

### 4.4 Доставка статики не менялась (MEDIUM, вне зоны 003)

Фаза 2 прежней дорожной карты не начиналась: скрипты в конце `body` без
`defer`, статика отдаётся Flask-воркером, кэширования nginx нет, локальных
vendor-копий нет (полная зависимость от доступности jsdelivr), CSP отсутствует.

### 4.5 Мелкие артефакты (INFO)

- `account.html`: класс `media` — удалён в BS5, работает только из-за пары
  `d-flex align-items-center` рядом; стоит убрать.
- `_head.html`: `shrink-to-fit=no` в viewport-мете — эхо BS4, не нужен.
- `base.css`: селектор `.highlight { font-weight: bold; }` — наследие старой
  разметки, в текущих шаблонах класс `highlight` не используется.
- Комментарий в `art_author.html` называет Markdown-движок «Python-mistune» —
  фактически используется `markdown` 3.9.

## 5. Итоговая оценка современности

| Уровень | Оценка |
|---|---|
| Парадигма и структура шаблонов | современные (2020-е) |
| Библиотеки | актуальные (Bootstrap 5.3.8, hljs 11.12.0, один CDN, SRI) |
| Собственный JS | современный стиль (IIFE, addEventListener, без inline) |
| Темы | современные (`data-bs-theme` + CSS-переменные, без вспышки) |
| Доставка статики | устаревшая (Flask вместо nginx, без defer, без CSP, без кэша) |

Разрыв «backend актуален — фронтенд середины 2010-х», зафиксированный прошлой
версией отчёта, устранён. Оставшийся отстающий слой — доставка статики (фаза 2)
и уборка хвостов миграции; детали — в [`03_improvements.md`](03_improvements.md).
