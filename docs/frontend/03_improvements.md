## 2. P1 — закончить миграцию

### 2.1 Удалить сайдбар-заглушку

Решение 6 задания 003 выполнено наполовину. Осталось:

- удалить `includes/_sidebar.html`;
- в `layout.html` заменить сетку `container-fluid` + `col-md-2`/`col-md-10` на
  обычный `container` (как и планировалось);
- вычистить из `base.css` блок `.margin-right-sidebar`, `.sidebar .nav-link`,
  `.sidebar .text-bg-*` (~25 строк).

Риск нулевой: на заглушку нет ни ссылок, ни JS, ни функциональности.

### 2.2 Понижение заголовков статьи — надёжнее, чем `replace`

`art_author.html` понижает `<h1>`→`<h2>` строковыми `replace`. Это сломается,
как только в теле статьи появится пример HTML с `<h1>` внутри `<pre><code>`.
Варианты по возрастанию трудозатрат:

1. **CSS**: стилизовать `.art-body h1` как h2 (не трогая разметку) — но тогда
   «ровно один `<h1>`» на странице соблюдается только визуально, в DOM их будет
   несколько;
2. **Сервер**: понижать заголовки в `render_article()`/маршруте честным разбором
   (например, `BeautifulSoup` или регэкспом с проверкой контекста) — но это правка
   Python-зоны;
3. **Оставить как есть**, зафиксировав ограничение комментарием: статьи не должны
   содержать `<h1>` внутри fenced-блоков. Минимум — поправить комментарий,
   ошибочно называющий движок «Python-mistune» (используется `markdown` 3.9).

### 2.3 Мелкие артефакты BS4-эхо

- `account.html`: убрать класс `media` (удалён в BS5; работает лишь из-за
  соседнего `d-flex`).
- `_head.html`: убрать `shrink-to-fit=no` из viewport-меты.
- `base.css`: удалить неиспользуемый селектор `.highlight { font-weight: bold; }`.

## 3. P2 — доставка статики (фаза 2 прежней дорожной карты)

### 3.1 Скрипты с `defer`

В `_scripts.html` добавить `defer` к Bootstrap bundle и highlight.js: `scripts.js`
и так ждёт `DOMContentLoaded`, порядок с Bootstrap JS не важен. Это снимает
рендер-блокирующую загрузку ~230 КБ JS.

### 3.2 Сократить предзагрузку тем hljs (опционально)

16 таблиц hljs в `<head>` — 16 запросов на каждой странице ради мгновенного
переключения. Если это окажется заметно (например, на медленных мобильных),
вариант: держать в `<head>` только активную тёмную тему и светлую `vs`, а
остальные подгружать подменой `href` при выборе в селекторе (с небольшим
кэшем выбранных). Трейдофф: первое переключение на «дальнюю» тему станет
асинхронным.

### 3.3 Статика через nginx

В `nginx/nginx.conf` добавить:

```nginx
location /static/ {
    alias /app/flaskblog/static/;
    expires 7d;
    add_header Cache-Control "public";
    gzip on; gzip_types text/css application/javascript;
}
```

Плюс `Cache-Control`/`ETag` для страниц статей — контент почти неизменяемый.
Снимает с gunicorn-воркера раздачу файлов.

### 3.4 Локальные копии или fallback

Сайт полностью зависит от `cdn.jsdelivr.net`: при его недоступности нет стилей,
навигации и подсветки. Варианты по возрастанию сложности: (а) `onerror`-fallback
на локальную копию; (б) скачать Bootstrap и highlight.js в `static/vendor/` и
раздавать свои. При появлении пункта 3.3 вариант (б) естественно ложится на nginx.

### 3.5 Минификация и CSP

- Минифицировать `base.css`/`scripts.js` на деплое (без build-этапа в рантайме).
- CSP: `default-src 'self'; script-src 'self' https://cdn.jsdelivr.net;` —
  единственный inline-JS (восстановление темы) потребует nonce или хэша; это
  осознанная цена, скрипт крошечный.
