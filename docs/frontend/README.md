## Краткое резюме

- **Архитектурный подход — современный и правильный.** Контентный сайт технических
  статей строится на серверном рендеринге (SSR): Jinja-шаблоны, никакого SPA. Это
  оправдано для SEO, простоты и скорости разработки. Менять парадигму не нужно.
- **Инструменты — устарели на 7-8 лет.** Bootstrap 4.0.0 (январь 2018) и jQuery
  3.2.1 (июнь 2017) — библиотеки середины 2010-х. jQuery в собственном коде не
  используется ни разу, Popper не используется вовсе.
- **Есть конкретные поломки фронтенда** (не связанные с версиями): на мобильных
  навигация не разворачивается (нет кнопки-тогглера), клик по пунктам сайдбара
  бросает `SyntaxError` в консоль, в подвале используются классы Bootstrap 5 при
  подключённом Bootstrap 4, поэтому стиль подвала частично не применяется.
- **Главные рекомендации.** Обновить Bootstrap 4.0.0 до 5.3.x (снимает jQuery и
  Popper, даёт CSS-переменные и нативную тёмную тему через `data-bs-theme`),
  вычистить JS (убрать inline `onclick`, починить сайдбар, добавить тогглер меню),
  перевести CDN на jsdelivr с SRI, отдавать статику через nginx. Tailwind оправдан
  только если проект готов ввести build-этап; для 17 шаблонов контентного сайта это
  оверхед.

## Замечание о расхождениях документации

`docs/01_project_structure.md`, `docs/02_architecture.md`, `docs/04_code_quality.md`
и `docs/05_optimization_roadmap.md` описывают **две** иерархии шаблонов
(`layout.html` и `new_art/art_base.html` с партиалами `new_art/includes/_art_*.html`)
и рассинхрон версий highlight.js между ними. В текущем дереве иерархия **одна**:
все шаблоны наследуют `layout.html`, каталог `new_art/includes/` и файл
`art_base.html` отсутствуют, highlight.js подключён в единственном экземпляре
(11.9.0). Пункты L5 (мёртвый шаблон `errors/new.html`) и часть L13 (рассинхрон
highlight.js) в `04_code_quality.md` также уже неактуальны. Отчёт ниже описывает
